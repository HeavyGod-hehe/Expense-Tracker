# 💰 Expense Tracker

A full-stack Expense Tracker I built while learning **Python, SQL, FastAPI, PostgreSQL, and SQLAlchemy**.

This project is part of my journey toward becoming an AI Engineer. Before jumping deeper into AI, I wanted to strengthen my backend fundamentals by actually building things.

## 🛠️ Tech Stack

- Python
- FastAPI
- PostgreSQL
- SQLAlchemy
- Pydantic
- JWT Authentication
- Password Hashing
- Streamlit

## ✨ Features

- User signup & login
- JWT authentication
- Password hashing
- Expense CRUD
- Category management
- User-specific expenses
- PostgreSQL relationships
- Simple Python frontend with Streamlit

## 🧠 What I Learned

This project helped me understand:

- Relational database design
- SQLAlchemy models and relationships
- JWT authentication
- Password security
- Pydantic schemas
- API design
- Connecting a frontend to a backend
- Debugging real database and authentication problems

## 📈 My Learning Progress

This was my second major FastAPI project after my **Inventory Management API** and came with a much more complex stack.

I started this project trying to understand everything myself. As the complexity increased, I became frustrated and eventually used AI more heavily to finish the project.

That taught me something important:

> **Using AI isn't the problem. Using it without understanding is.**

I'm learning to use AI as a tool for explaining, debugging, and learning rather than letting it replace the learning process.
